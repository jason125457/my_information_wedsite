# First Vertical Slice Plan

1. Establish the Next.js App Router, TypeScript, Tailwind CSS, and reusable UI foundation.
2. Add server/browser Supabase clients and a single-user Magic Link flow guarded by `ALLOWED_EMAIL`.
3. Define the initial PostgreSQL schema, seed topics, and protect all tables with Row Level Security.
4. Ship a calm, responsive feed backed by trustworthy seeded examples and local interaction state.
5. Verify the access contract with focused tests, then document and run the complete local setup workflow.

External collectors, AI ranking, persistent feed actions, digests, and LINE notifications remain intentionally out of this slice.
